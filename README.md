Time extractor

Программа считает время сотрудников второй линии отдельно по чатам и тикетам.

Диалоги

Загружает JSON с массивом Dialogs или получает данные из HTTP-сервиса 1С.

Определяет сотрудников по компании автора.

Последовательные сообщения первой линии считает одним вопросом.

Точка отсчёта — последнее сообщение первой линии перед первым ответом второй линии.

Ответ быстрее 10 секунд учитывается как 10 секунд.

Ответ от 10 секунд до 15 минут учитывается по фактическому интервалу.

Ответ более чем через 15 минут не учитывается.

Системные сообщения и повторные ответы без нового вопроса не учитываются.

Тикеты

Программа принимает файлы .xls и .xlsx за выбранный период.

В расчёт включаются только завершённые тикеты. Выполняющиеся, отменённые идругие незавершённые тикеты не учитываются.

Для каждого завершённого тикета считаются два независимых показателя:

Время от создания до закрытия:

Заявка закрыта − Заявка открыта − Длительность пауз

Реальное рабочее время из поля Длительность.

Значение 0:00 в поле Длительность считается незаполненным и показываетсякак Не заполнено.

Результаты группируются:

по сотрудникам;

по видам работ;

по приоритетам.

Для каждой группы показываются количество завершённых тикетов, суммарное времяот создания до закрытия без пауз и суммарная длительность работ.

Обязательные столбцы:

№;

Статус;

Приоритет;

Вид работ;

Исполнитель;

Длительность;

Заявка открыта;

Заявка закрыта.

Столбец Длительность пауз необязателен. Если его нет, программа предупреждаетоб этом и принимает паузы равными нулю.

Запуск

Откройте папку проекта в VS Code.

Запустите proxy:

node server.js

Откройте index.html через Live Server.

Файлы xlsx.full.min.js и XLSX-LICENSE.txt должны находиться в корне проекта.
