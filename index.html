Как рассчитывается время чатов

Это расчётное активное время, а не фактический табель. Для каждого несистемного сообщения сотрудника берётся интервал от предыдущего несистемного сообщения в диалоге.

Интервал ограничивается максимумом 15 минут и минимумом 30 секунд на сообщение. Значения можно изменить в настройках.

Системные сообщения не учитываются. Если отвечали несколько сотрудников, время распределяется по авторам сообщений.

1. Источник данных заявок

Ожидаются столбцы: Время создания, Линия, Тип заявки, Исполнитель, Срок заявки, Длительность работы (сек).

Поддерживаются заголовки: Период, ID заявки / Идентификатор заявки, № заявки / Номер заявки, Новый статус / Новое значение. Строка заголовков может находиться не в первой строке Excel.

Историю можно вернуть вместе с заявками в массиве StatusHistory или загрузить по отдельному URL. Для расчёта общего времени и дедлайнов история статусов обязательна.

2. Отработанное время сотрудников

Рабочие дни и норма часов рассчитываются по производственному календарю РФ для пятидневной 40-часовой недели. В программу встроен календарь 2026 года с праздничными, перенесёнными выходными и сокращёнными предпраздничными днями. Фактически отработанные часы вводятся отдельно по каждому сотруднику — их можно уменьшить с учётом отпусков, отгулов, больничных и других отсутствий.

В сводку входят только завершённые заявки. «Фактическое время работ» — сумма стандартного времени тематик. Норма часов берётся из производственного календаря РФ. Фактически отработанные часы вводятся вручную по каждому сотруднику. Процент времени = нормативное время по тематикам ÷ фактически отработанные часы. Процент просроченных = просроченные ÷ завершённые заявки, для которых удалось определить и дедлайн, и фактическое время завершения.
